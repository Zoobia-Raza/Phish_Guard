How to triage

INSPECT

Read the sender, subject, links and attachments in the transmission panel. Hover any link to preview where it really resolves.

VERIFY THE POSTMARK

Hold the FROM row (or hold V) to flip the envelope in 3D and read its postmark. Lookalike domains hide there — rn pretending to be m, 0 pretending to be O, innocent-looking suffixes like "-secure.com".

DECIDE

Grab the envelope and hurl it into a gate — left FILE for legitimate mail, right REPORT for phishing. Arrow keys or the buttons work too.

BEAT THE CLOCK

The ring around the envelope is your timer. A missed intercept counts as a breach, and three breaches end the shift. Correct calls in a row build a score multiplier.
